# acme-shop — a kgai demo project

A fictional online shop, as its team shaped it between February and August 2026: the
checkout, billing, payments and the rest — **61 decisions by three people**, recorded
with kgai. The code is stubs; the decisions are the point.

Copy this folder somewhere of its own first — kgai finds a project's store at the root
of its git worktree, so inside the kgai repository this folder would show kgai's own
decisions instead:

```bash
cp -r examples/acme-shop ~/acme-shop && cd ~/acme-shop && git init -q
```

Open it in VS Code with the **kgai** extension installed and the sidebar fills with the
project's decisions, elements, the one open conflict and the people. Or ask `kg` from a
terminal in the folder — once, `kg rebuild` projects the log into the graph database
(the log is what ships; the database is derived):

```bash
kg rebuild                            # once: the graph from the 61 events in the log
kg context --about "Invoice"          # what governs Invoice today, and why
kg history "feature:Invoice"          # how it got there: part of Pricing, then not
kg conflicts                          # the Refund Window: 14 days vs 30, unresolved
kg as-of 2026-04-30                   # the whole graph as it stood at the end of April
kg search "why did payments move to stripe"
```

The store lives in `.kgai/store` (the default location) — the log shards of the three
installs (`i-alice`, `i-bob`, `i-carol`) plus a config that makes you *alice*. Nothing
here is real: no company, no people, no code.

The story in the log:

- **February** — the shop's shape: Checkout, Cart, Orders in PostgreSQL, Invoice as part
  of Pricing (a mistake, fixed in March), payments through Braintree.
- **March** — billing takes shape: the Tax Service, the Invoice Renderer, discounts, a
  rejected idea recorded (PDF-only invoices).
- **April** — orders get a state machine; refunds and the Refund Window; shipping — and
  two people record two free-shipping thresholds on the same morning (a conflict).
- **May** — the conflict is resolved at 60; payments move from Braintree to Stripe; the
  cart moves to Redis; PCI scope is drawn.
- **June–July** — search on Meilisearch, archives in S3, retention, rate limiting,
  subscriptions; details that stick.
- **August** — the Refund Window is changed twice, concurrently: 14 days from delivery
  versus 30 from payment. Still open — record a decision on it to resolve it.
